# CBT Planner（QB・モントレ）— みんな用

元の CBT Planner から、個人の予定・模試・初期データとクラウド同期を外した配布版です。

- 問題集：QB（3,359問）・モントレ（3,573問）
- 最初に開くと「CBT本番日」と「1日の目標」を聞かれます（あとで「対策」タブ →「基本設定」で変更可）
- 本番の4週間前から直前期モード（残り日数と勉強時間から、今日やる章・問題数を自動で割り振り）
- データはその人の端末（ブラウザ）の中だけに保存。ほかの人とは混ざりません
  - 機種変更のときは「対策」タブ →「バックアップ書き出し」→ 新しい端末で「復元」
- iPhone は Safari で開いて「共有 → ホーム画面に追加」するとアプリのように使えます
