# ヨミの塔 — 設計書

Kioku のゲームタブに入れる、1人用の読み合いモンスターバトル × ローグライク。
勉強で貯めた 🎟 プレイ券で塔を登る。

---

## 0. 何を目指すか

- **読みが当たる快感**を、1人用でも理不尽にならない形で作る。ポケモン対戦の「交代読み」「受け出し」の気持ちよさを、相手の心を読めるかどうかの勝負として再現する。
- **育てて、強くなって、塔を登りきる**達成感（ヌルい育成ではなく、勝てる強さを自分で組む）。
- **遊ぶほどプレイヤー自身がうまくなる**ゲーム。運で勝つのではなく、読みと計画で勝つ。

### 既存作との違い（ここがオリジナル）

| | よくある形 | ヨミの塔 |
|---|---|---|
| 敵の予告 | 1つ予告して、そのまま実行（Slay the Spire 系） | **2つ予告して、どちらか1つだけ実行**。どちらになるかは「性格」で決まる |
| 敵のAI | ランダム（理不尽）か、固定（作業） | 性格は**見える状態のルール**。状態を操れば、敵の選択を**こちらが誘導できる** |
| 性格 | 飾り | 最初は候補が2〜3つで、**行動を見て絞り込む推理**がある |
| 読み勝ち | 演出だけ | ゲージになり、**情報（看破）か火力（必殺）か**を選んで使う資源になる |

一言でいうと「**相手の心が少しだけ見えるポケモン対戦**」。毎ターンが小さなパズルで、ランは育成と編成の勝負。

## 1. 1ターンの流れ

自分も敵も最大3体。場に出るのは1体ずつ。

1. **敵が予告する**：ターンのはじめに、敵は行動を2つ見せる。
   - **A**：攻め（今の自分の場のモンスターにいちばん効く攻撃）
   - **B**：対応（交代・変化技・守る・自分の交代先を狙う技 など）
2. **性格が A か B を決める**：決め方は性格ごとのルール（下の表）。ルールはターンのはじめの状態で判定される。
   - 性格がわかっていれば、どちらが来るか**確定**で表示する。
   - 候補が複数で、候補どうしの答えが割れているときだけ「？」になる（そのターンだけの不確実さ）。
3. **自分が選ぶ**：技4つ・交代・看破（ゲージ1）・必殺（ゲージ3）。
   - 行動を選ぶと、**「Aなら」「Bなら」の2つの結果**（与えるダメージ・受けるダメージ・倒せるか・読み勝ちになるか）をその場で見せる。計算はゲームがやる。
4. **処理**：交代 → 技（優先度 → 素早さ。同じ速さなら自分が先）→ ターン終わりの効果。乱数はない（命中・急所・追加効果の確率なし）。
5. **倒れたら**：自分は好きな仲間を出す（相手は動かない）。敵は「次に出てくる」仲間が先に表示されている。

### 読み勝ち（ヨミゲージが1つ溜まる）

| 名前 | 条件 |
|---|---|
| 受け読み | 自分が交代し、敵の攻撃を交代先が**半分以下**で受けた |
| 交代読み | 敵が交代し、自分の攻撃が交代先に**2倍**で入った |
| 守り読み | 自分の「まもる」が攻撃を防いだ |
| 積み読み | 敵が攻撃してこないターンに、自分が能力を上げた |

ヨミゲージは最大3。使い道は2つで、**情報か火力か**を選ぶ：

- **看破（1）**：このターン、敵が A と B のどちらをやるかを見る（性格も1つに絞れる）
- **必殺（3）**：場のモンスター固有のヨミ技（威力130・自分のタイプ・まもるを貫通・固有の追加効果）

最後の1体を「読み勝ちしたターン」か「必殺」で倒すと、その敵が**仲間になりたがる**。

## 2. 性格

性格は A/B の選び方のルール。ルールは常に見られる。敵の種族ごとに「なりやすい性格」が2〜3個あり、個体はその中の1つ。

| 段階 | 性格 | ルール |
|---|---|---|
| 1層〜 | 短気 | いつも A |
| | 臆病 | 自分のHPが半分以下か、自分の場のモンスターが2倍の技を持っていると B。それ以外は A |
| | 頑固 | 前のターンと同じ記号（出てきた最初のターンは A） |
| 2層〜 | 天邪鬼 | 前のターンに自分が攻撃技を使っていたら B、それ以外（交代・変化・まもる）なら A |
| | 見栄っ張り | A で倒せるか、A が2倍なら A。それ以外は B |
| | 気まぐれ | 毎ターン半々（唯一の運。両方に耐える手が試される） |
| | 律儀 | A と B を1ターンごとに交互に出す（出てきた最初は A） |
| 3層〜 | 慎重 | 自分の場のモンスターの方が速ければ B、遅ければ A |
| | 執念 | 前のターンにダメージを受けていたら A（やり返す）、受けていなければ B |
| | 策士 | 自分が前のターンと同じ行動をすると読んで、それに強い方を選ぶ |
| ボス | 王の眼 | このバトルで自分がいちばん多く選んだ種類（攻撃／交代・守り・変化）を読んで、それに強い方 |

### 推理と誘導（ここが上達の中心）

- 候補が「短気／臆病」のとき、敵のHPが半分より上で、自分が2倍の技を持っていなければ、両方とも A を選ぶ → **確定**。
- わざと敵のHPを半分以下に削ると答えが割れる → 次のターンの行動を見れば性格がわかる（**探り**）。
- 性格がわかれば、状態を操って**敵に選ばせたい方を選ばせる**（**誘導**）。例：天邪鬼には、わざと交代して次のターンに攻撃を誘い、受けの得意な仲間で受ける。
- 読めない（気まぐれ・割れている）ターンは、**どちらにも耐える手**（両方を半分で受けられる交代先、どちらにも等倍で入る技）を探す。

## 3. タイプ（6つ・覚えやすい輪）

```
        炎
     岩    氷
     水    草
        雷
```

並びは 炎 → 氷 → 草 → 雷 → 水 → 岩 → 炎（時計回り）。

- **時計回りに2つ先まで2倍**（炎は 氷・草 に2倍）
- **真向かいは等倍**（炎と雷）
- **それ以外は半分**（反時計回りの2つと、同じタイプ）

中身は2つの三すくみの組み合わせ：おなじみの「炎 → 草 → 水 → 炎」と、新しい「氷 → 雷 → 岩 → 氷」。
どのタイプも「2倍で入る相手2つ・弱点2つ・半減3つ・等倍1つ」で、強弱の偏りがない。
技には無タイプもある（どれにも等倍）。自分と同じタイプの技は威力 ×1.25。

---

## 4. モンスターと技

- 能力は HP・攻撃・防御・素早さの4つ（特殊はない）。レベルで伸びる。
- 6タイプ × 3段階進化の系統（6系統・18体）＋ 2段階の系統（5系統・10体）＋ ボス4体。
- 系統ごとに役割がある：速攻・壁・交代役（攻撃して下がる）・積み・状態異常・設置。
- 技は約45種。分類：攻撃（威力40〜120）、先制、吸収、交代技（攻撃して下がる）、まもる、能力アップ、状態異常（やけど・どく・まひ）、回復、設置（交代で出てきた相手にダメージ）。
- 状態異常は確率なしの確定効果：やけど＝攻撃半分＋毎ターン1/16、どく＝毎ターン1/8、まひ＝素早さ半分。
- 能力の上げ下げは ±2 段階まで（1段階 ×1.5）。交代するともとに戻る。
- ダメージ式は固定（乱数なし）。同じレベルどうしで、等倍の一致技（威力80）が HP の約35%。

## 5. ラン（塔を登る）

- **4層**。各層は7段の分かれ道マップ ＋ 層の主（ボス）。
- マス：野良戦（敵1〜2体）・強敵（3体・秘宝）・仲間（3体から1体）・技（技を覚える）・休憩（回復か修行）・店・事件（選択肢つきのイベント）・層の主。
- 最初の仲間（スターター）に加えて、タイプの違う「相棒」を3体から1体選んでスタートする（交代がこのゲームの核なので）。
- 仲間は最大6体。**戦う前に相手の3体（種族・レベル・性格の候補）を見てから、連れていく3体と先頭を選ぶ**（ポケモンの見せ合い）。
- HP は戦闘をまたいで持ち越し。勝つと生きている仲間は15%回復、休憩は全回復（倒れた仲間も起きる）、層の主を倒すと全員全回復。連れていった3体が全員倒れたらランは終わり。
- じこさいせいは1戦2回まで。読み勝ちは「本当に痛い一撃をかわした・まもった」ときだけ（予告どおりの攻撃をまもり続けてもゲージは溜まらない）。
- 経験値で レベルアップ → 3段階の系統は Lv9・Lv16、2段階は Lv12 で進化して新しい技。
- **持ち物**（1体に1つ・12種）と **秘宝**（チーム全体・16種）でビルドを作る。
  - 例：読みビルド（読み勝ちでゲージ+2、看破タダ）、受けビルド（交代先の被ダメ減、下がると回復）、速攻ビルド（初手先制、威力アップ）。
- **層の主**は固有の「掟」を持つ：
  1. 苔の番人（岩）：掟「番人の岩の技の威力 ×1.3」。律儀（A と B を交互）。B のターンに積む・交代する、という最初の読みを教えるボス
  2. 鏡の魔女（氷）：掟「同じ攻撃技を2回続けると跳ね返される」「魔女の能力は下がらない」。天邪鬼
  3. 雷帝ナルカミ（雷）：掟「遅い方が先に動く」「雷の技の威力 ×1.3（自分も）」。素早さの読みがひっくり返る
  4. ヨミの王：掟「王の眼（自分の癖を読む）」「HPが半分を切るとタイプが変わる」

### 図鑑と上達

- 会った種族と、見抜いた性格の数が図鑑に残る。最初に選べるのは炎・水・草の3体。クリアなどで氷・雷・岩も選べるようになる。
- クリアするたびに**難しさ Lv** が上がる（敵のレベル、性格の候補数、ボスの掟が増える）。

## 6. 券（勉強とのつながり）

勉強のやり方には一切手を入れない。今まで通り「QB 1問＝券1枚、カード5回＝券1枚」。

| マス | 券 |
|---|---|
| 野良戦 | 3 |
| 強敵 | 5 |
| 層の主 | 7 |
| それ以外 | 0 |

1層 ≒ 21枚、1ラン ≒ 80枚（＝QB 80問くらい）。毎日のノルマ（QB 20問＋カード）だけでも 1日1層ずつ登れる。
ランは途中でいつでもやめて、続きから再開できる（1ターンごとに保存）。

## 7. 画面

- **ハブ**：塔の絵（今どこまで登ったか）・はじめる／つづきから・図鑑・遊び方。
- **マップ**：下から上に登る分かれ道。マスはドット絵のアイコン。
- **見せ合い**：相手3体と自分の仲間を並べて、連れていく3体と先頭を選ぶ。
- **戦闘**：上に敵、下に自分（ポケモンの配置）。その間に **A／B の予告カード**（どの性格の候補がどちらを選ぶか、確定かどうか）。下に技4つ・交代・ゲージ。行動を選ぶと「Aなら／Bなら」の結果が出て、決定で実行。
- **演出**：攻撃の踏み込み、被弾の点滅と揺れ、HPバーが減る、ダメージ数字、交代のスライド、**読み勝ちのカットイン**、ゲージが光る、進化、レベルアップ音。
- 文字は DotGothic16。390px 幅で片手で遊べること。

## 8. バランスの決め方

ルールは `yomi-core.js`（DOMなし・node で動く）。ボットに数千回遊ばせて数字を決める。

| ボット | 遊び方 |
|---|---|
| ランダム | でたらめに選ぶ |
| 読まない | 今の敵にいちばん効く技を撃つだけ（予告を見ない） |
| 守り重視 | A と B の両方の結果を見て、平均でいちばん良い手 |
| 読み上手 | 性格の推理・確定の利用・看破と必殺の使い分け・2手先まで読む |

目標（難しさ Lv1・ラン全体のクリア率）：読み上手 40〜50%、守り重視 15〜25%、読まない 5%未満、ランダム 0%。

調整後の結果（2026/11）：読まない 0%、守り重視 約25%、読み上手（2手先まで読むボット）約30%。ボットは地図の選び方が単純なので、人が読みと編成を考えればもっと上に行ける位置にしてある。
道具：`tools/yomi-bench.js`（条件をそろえた1戦の勝率）、`tools/yomi-run.js`（ラン全体）、`tools/yomi-demo.js`（1戦を文字で流す）。
ドット絵は `tools/yomi_masks.py`（形）→ `tools/yomi_sprites.py`（縁取り・陰影）→ `yomi-art-data.js`。
「読める人が勝てて、読めない人は負ける」こと。
